# Repetrail: карточки и повторение

- `repetrail.svg` — цветной векторный исходник выбранной иконки. Только контуры: без встроенных растров, фильтров и шрифтов.
- `repetrail-notification.svg` — отдельный монохромный исходник на прозрачном фоне с вырезом в форме стрелки повторения.

## Android

Цветной значок подключён через существующие `@mipmap/ic_launcher` и `@mipmap/ic_launcher_round`. Фон и передний план — VectorDrawable. Передний план в SVG имеет оптическую поправку `translate(2 -2)`: большая светлая карточка иначе визуально уводит рисунок влево и вниз. Та же поправка перенесена в `drawable-v24/ic_launcher_foreground.xml`: масштаб 0.78, смещение X = 16.56 и Y = 13.44 внутри слоя 108×108dp. Она укладывается в центральную безопасную область 66×66dp.

На Android 13+ добавлен отдельный слой `@drawable/ic_launcher_monochrome` для тематических значков.

Для будущих уведомлений используйте:

```kotlin
.setSmallIcon(R.drawable.ic_stat_repetrail)
```

`ic_stat_repetrail.xml` — VectorDrawable 24×24dp: белые контуры и прозрачный вырез, без фона. Это самостоятельная упрощённая версия для небольшого размера, со скруглёнными концами задней карточки и стрелки. Оптическая поправка в SVG и VectorDrawable: X = −0.5, Y = −0.35 в координатах 24×24; тематический слой использует ту же геометрию с масштабом 2.8. Кода отправки уведомлений в приложении пока нет.

## iOS

AppIcon требует PNG-экспорт; редактируемым исходником остаётся SVG. Экспортируйте цветной `repetrail.svg` в непрозрачный PNG 1024×1024 без скругления углов. Скругление применяет система.

При изменении SVG синхронизируйте соответствующие Android-контуры и обновите PNG-экспорт iOS.

Официальные требования: [адаптивные иконки Android](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive), [иконки уведомлений](https://developer.android.com/studio/write/create-app-icons#notification).
