# core:domain

Общие бизнес-модели, контракты репозиториев и use cases размещаются в `commonMain`.

Правила модуля:
- Разрешена зависимость от `core:common` и Kotlin/coroutines.
- Запрещены зависимости от Compose, Room, Koin, data- и UI-модулей.
- Бизнес-код не использует Android/iOS API: платформенные реализации подключаются через интерфейсы.
- Диспетчеры и источник времени передаются через конструктор, если нужны бизнес-логике.
- Контракты репозиториев и use cases добавляются вместе с конкретной CRUD-функциональностью; пустые заготовки заранее не создаются.

Модуль компилируется для Android, `iosArm64` и `iosSimulatorArm64`. Платформенные таргеты нужны для потребления общего кода, а не для размещения в domain платформенных реализаций.
