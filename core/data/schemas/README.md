# Room schemas

Room Gradle plugin exports schemas here. Keep generated JSON files in Git.

The initial database version is 1. Its generated schema is expected at:
`com.breckneck.core.data.local.RepetrailDatabase/1.json`.

The v1 JSON was generated by Room/KSP during the user's build and is tracked in Git.
Do not handwrite schema JSON: regenerate it with Room/KSP and review changes before committing.
No migration is needed until the schema first changes.
